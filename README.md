# إدارة عقارات جمعية الراكة — إدارة عقارات جمعية الراكة

نسخة PRO خفيفة ومتجاوبة للجوال والكمبيوتر.

## المميزات
- واجهة دخول حديثة برقم سري.
- لوحة رئيسية احترافية.
- إدارة العمارات والعدادات.
- إدخال الإيرادات والمصروفات.
- كهرباء ومياه: تسجيل مبلغ كل عداد مستقلًا.
- تعديل وحذف العمليات.
- تقارير شهرية قابلة للطباعة A4.
- تصميم عربي RTL بخط Cairo.
- بدون مكتبات JavaScript ثقيلة.

## التقنية
- Supabase Auth لتسجيل الدخول.
- Supabase Database لتخزين العمارات والعدادات والعمليات والأصناف.
- GitHub Pages للنشر.
